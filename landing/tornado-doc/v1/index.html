tdoc

tornado-doc · open source

Google Docs, but for documents your agent writes.

Turn a prompt into an interactive HTML document and share it as a live URL. Anyone with the link comments on any sentence, image, or chart. Your agent reads those same comments as structured input and writes the next version — then replies on each thread with what it changed.

Install in ~3 minutes GitHub

The problem

You are the router between your colleagues' comments and your agent. Every round, by hand.

A nice UI for people — Google Docs, a Slack thread, screenshots — means you copy-paste all of it back into the chat yourself.
Clean input for the agent — raw JSON, "edit line 47" — means nobody wants to write the feedback.

And a document generated in a chat window has no history. Every regeneration overwrites the last one.

The loop

What you get

  • Comment on anything. Highlight a sentence across paragraphs, bold, and links — or hover an image, SVG, chart, video, or code block and comment on that. Anchors survive regeneration.
  • Status that syncs both ways. When your agent applies feedback it stamps each thread ✅ applied, 🟡 partial, or ❓ needs clarification, so reviewers see what landed without re-pinging you.
  • Every version is a full snapshot. Flip back to any past version. Comments on text a later version deleted are preserved, never silently dropped.
  • Multiplayer that doesn't clobber. Readers sign in once with GitHub. Concurrent comments are serialized per document, so two people commenting at the same instant both land.
  • Your infrastructure, $0. Publishing deploys to a Cloudflare or Vercel account you own, inside free tiers personal use won't reach. Nobody else — including us — sees your traffic or pays your bills.

Install

Paste this into Claude Code or Codex. It clones the repo, runs the doctor, walks you through the couple of browser clicks, and ends on a published URL.

Install tdoc by following https://github.com/tornado-doc/tdoc/blob/main/ONBOARDING.md

Then: /tdoc new "an explainer with a slider showing how interest compounds" → /tdoc publish → send the link.

Templates

Pick a look, see it live, copy one line, hand it to your agent. tdoc has no editor — you describe the doc, the agent writes it in the style you name.

How it works

1Pick a card and hit See live example — the look, rendered in a real doc.
2In the example (or on the card) hit Copy the prompt, then just type your topic at the end — no mid-line editing.
3Paste it to your agent. It generates the doc in that style, serves it locally, and can publish it here. Comment on it, and it regenerates.

The looks

default — stark sans

White, black, one clean sans, an oversized headline, and a technical-diagram vocabulary (frames, mono labels, dot/hatch textures). The house default.

Notes

·Name no style and you get default. Every style follows the same floor: no AI-slop prose, and visual-first — many charts and diagrams, not walls of text.
·The style sets the look; it never limits which visuals a doc has. Ask for a bar chart, a timeline, a matrix — any style draws them in its own palette.

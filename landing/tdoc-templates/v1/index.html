Templates

Pick a look, copy one line, hand it to your agent. tdoc has no editor — you describe the doc, the agent writes it in the style you name.

How it works

1Pick a card below and copy its prompt line (it's one selectable line).
2Paste it to your agent, then just type your topic at the end — no mid-line editing.
3The agent generates the doc in that style, serves it locally, and can publish it here. Comment on it, and it regenerates.

Notes

·Name no style and you get default. Every style follows the same floor: no AI-slop prose, and visual-first — many charts and diagrams, not walls of text.
·The style sets the look; it never limits which visuals a doc has. Ask for a bar chart, a timeline, a matrix — any style draws them in its own palette.
